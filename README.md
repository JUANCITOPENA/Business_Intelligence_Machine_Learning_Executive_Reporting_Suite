🚀 BI & Machine Learning Executive Suite
📊 De Datos Crudos a Decisiones Ejecutivas
Suite analítica integral desarrollada en Python para transformar datos transaccionales en información estratégica mediante Business Intelligence, Analítica Financiera, Machine Learning y Generación Automática de Reportes Ejecutivos en PDF.

🎯 Objetivo del Proyecto
Construir una solución empresarial capaz de:

✅ Consolidar datos transaccionales.
✅ Calcular KPIs financieros y comerciales.
✅ Aplicar modelos de Machine Learning.
✅ Detectar patrones, anomalías y oportunidades.
✅ Generar dashboards ejecutivos (16:9).
✅ Automatizar la creación de un dossier ejecutivo profesional en PDF.

▶️ Ejecución
1️⃣ Crear entorno virtual
python -m venv .venv
2️⃣ Activar entorno virtual
Windows

.venv\Scripts\activate
Linux / macOS

source .venv/bin/activate
3️⃣ Instalar dependencias
pip install -r requirements.txt
4️⃣ Ejecutar el proyecto
python ml_analisis.py
